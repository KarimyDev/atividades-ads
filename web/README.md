# Portfólio pessoal - Karimy Carvalho Alves

Projeto desenvolvido para a atividade prática de Fundamentos da Programação Web.

## Tecnologias usadas

- HTML5
- CSS3
- JavaScript

O projeto foi feito sem frameworks, conforme solicitado no enunciado.

## Estrutura

- `index.html`: estrutura principal do portfólio
- `estilo.css`: estilos, responsividade e tema claro/escuro
- `script.js`: menu responsivo, troca de tema e validação do formulário

## Seções obrigatórias

- Sobre mim
- Formação
- Portfólio
- Contato

## Publicação no GitHub Pages

1. Criar um repositório público no GitHub.
2. Enviar os arquivos `index.html`, `estilo.css`, `script.js` e `README.md`.
3. Entrar em `Settings > Pages`.
4. Em `Branch`, selecionar `main` e a pasta `/root`.
5. Salvar e aguardar o GitHub gerar o link público.

O link publicado deve abrir o site diretamente no navegador e não pode conter `localhost` ou `127.0.0.1`.
